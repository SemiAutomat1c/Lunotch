# Contributing to Lunotch

Lunotch is a personal, experimental GPL-3.0 fork of [Boring Notch](https://github.com/TheBoredTeam/boring.notch). Issues and small, focused pull requests are welcome, but response times and maintenance are best-effort.

Open an issue with macOS version, Mac model, steps to reproduce, and expected versus actual results. Please do not attach sensitive information or private logs. Run the app in Xcode and follow [docs/LOCAL_TESTING.md](docs/LOCAL_TESTING.md) before proposing behavior changes. For a PR, describe the change, any permissions it affects, and the checks you performed. Keep the upstream copyright/license notices intact.

For improvements intended for the original Boring Notch project rather than Lunotch's fork-specific changes, consider contributing to [TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch) directly.
